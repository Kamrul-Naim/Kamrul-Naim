## 🌾 Farm2Shop

### Direct Farmer-to-Shopkeeper Egg Supply Platform

Farm2Shop is a full-stack MERN marketplace designed to connect **egg farmers directly with shopkeepers**.

Farmers can upload their available egg stock and products, while shopkeepers can browse the marketplace, view available products, place orders, and purchase eggs directly from farmers.

### ✨ Key Features

|       | Feature                    | Description                                      |
| :---: | -------------------------- | ------------------------------------------------ |
| 👨‍🌾 | **Farmer Marketplace**     | Farmers can upload and manage their egg products |
|   🏪  | **Shopkeeper Marketplace** | Shopkeepers can browse available egg products    |
|   🛒  | **Purchasing System**      | Shopkeepers can purchase products from farmers   |
|   🔐  | **Authentication**         | Secure authentication with role-based access     |
|   📦  | **Order Management**       | Complete product and order management workflow   |
|   💳  | **Online Payment**         | Integrated online payment system                 |
|   🔔  | **Notifications**          | User notification system                         |
|   ⏳   | **Product Expiration**     | Automatic product availability handling          |
|  🛠️  | **Admin Panel**            | Platform-wide management and monitoring          |
|   🌐  | **Deployment**             | Separate frontend, admin and backend deployment  |

## 🩺 PulseCare

### Medical Appointment Management System

PulseCare is a full-stack MERN medical appointment management platform designed around **three different user roles: Patients, Doctors, and Admins**.

Each role has its own authentication flow, dashboard, permissions, and functionality.

### ✨ Key Features

#### 👤 Patient

* Secure registration and login
* Browse available doctors
* Search and filter doctors by specialty
* View detailed doctor profiles
* Book appointments using available dates and time slots
* View upcoming and previous appointments
* Cancel appointments
* Update personal profile information
* Upload and update profile picture
* Secure logout

#### 🩺 Doctor

* Secure doctor authentication
* Personalized doctor dashboard
* View total appointments and patients
* View appointment details
* Manage appointment status
* Mark appointments as completed
* Cancel appointments
* Update doctor profile information
* Update consultation fees, address, description, and other details
* Toggle doctor availability

#### 🛠️ Admin

* Secure admin authentication
* View overall system statistics
* Add new doctors
* View all registered doctors
* Update doctor information
* Delete doctor profiles
* View and manage all appointments
* Cancel appointments
* Mark appointments as completed
* Monitor recent bookings and system activity

## 🎬 MovieHub

### Movie Discovery & Favorites Application

MovieHub is a responsive movie discovery application built with **React, Vite, and the TMDB API**.

Users can browse popular movies, search for movies by title, and save their favorite movies for later.

### ✨ Features

* 🎥 Browse popular movies
* 🔍 Search movies by title
* ❤️ Add and remove movies from favorites
* 💾 Persist favorites using Local Storage
* 📱 Fully responsive design
* ⚡ Fast performance powered by Vite
* 🎨 Clean and modern user interface
